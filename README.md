# 图像放大模型的像素重排相位约束训练

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

前向用交叉相关，步长 1，所有相位核为 3×3。每相位的参数表逐槽映射到 shared，null 表示无该槽。以 2 倍空间重排为例，相位为 (输出 y mod 2, 输出 x mod 2)，低分辨率坐标对应各轴除 2 向下取整。项目权重统一 scale，普通参数代表 code*scale，ties-to-even 后夹至 [-127,127]。每个设备相位 maximum weight error 为活跃槽位逐值的绝对误差上限。高精槽按共享 id 占用且所有引用读取同一数值。用连续前向计算输入和参数梯度，整数导出不进入训练求导。 每个设备相位输出误差门槛只考虑其有效槽。如果无法让所有相位达标，以设备给的 priority 顺序比较各可行方案的达标向量，先比较最高优先级相位，再依次向后。输出同时指明各未达标相位所欠的精度。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。window 和 seed 引用监督窗 ID。region 是高分辨率图的半开矩形 [x0,y0,x1,y1]，grad 按行给对应梯度。export 请求设备权重。
