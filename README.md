# 手机语音唤醒的核均值张量与样本门限交接

这里的核码本、录音特征和观测权重是用于设备联调的合成资料。使用 Node.js 22。运行 `npm ci --offline` 核对依赖锁，`npm run inspect` 查看资料字段，`npm test` 检查资料格式及相互引用。检视脚本只读取元数据。

## 数据格式

默认核是 exp(−||x−y||²/(2σ²))。同侧分子为不同 physicalGroup 之间 w_i*w_j*k 的有序和，分母为同一集合的 w_i*w_j 和，跨侧同组也排除并按自身分母。不参与的组无梯度。见证读数对单 query 给两侧按权重的核均值之差，若 query 身份在该侧则该组从分子分母排除。最终接受策略为距离上界 ≤accept 或下界 ≥reject，其余等待核证据。可用 approximate 列给离线设备的特征映射和每个 key 的统一最大核误差。近似的梯度仅可用于派生误差合同声明的路径，报使用了何种导数。budgetBytes 包含暂存数据；pairLimit 计典型读取中真实精确成对核求值数。 small-v1 是预装设备模型，kernelCode 提供它的固定的离散特征域，kernelSketch 提供设备发布的近似特征。训练态的实数输入仍需按精确核引用梯度，不能把编码近似外推到表外。不能从核距离单独推定阈值可携带，迁移只在两边用可比较投影且录音上限下界满足门限时允许。 第二代录音可能仅交付 scaledV2 视图而缺共同的可核验投影身份。接收仅标明维度相等不能建立共同空间。 梯度请求对应指定 query 的核见证与明确的训练特征输入，pairLimit 以一轮设备阈值决定所用的精确核对计，不把单 query 伴随算入前一决定。

## 取数

`inputs/microphone-samples.json` 保存标定、规格和调用记录。记录中的范围除明确说明外从零开始，使用半开区间。批量数组按调用记录列出的顺序交付。kernelRow(side,index) 返回录音特征与物理组，kernelCode(code) 和 kernelSketch(code) 是设备公开的输入码本及近似特征。
