# 图像放大模型的像素重排相位约束训练

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

前向用交叉相关，步长 1，所有相位核为 3×3。每相位的参数表逐槽映射到 shared，null 表示无该槽。以 2 倍空间重排为例，相位为 (输出 y mod 2, 输出 x mod 2)，低分辨率坐标对应各轴除 2 向下取整。项目权重统一 scale，普通参数代表 code*scale，ties-to-even 后夹至 [-127,127]。每个设备相位 maximum weight error 为活跃槽位逐值的绝对误差上限。高精槽按共享 id 占用且所有引用读取同一数值。用连续前向计算输入和参数梯度，整数导出不进入训练求导。 每个设备相位输出误差门槛只考虑其有效槽。如果无法让所有相位达标，以设备给的 priority 顺序比较各可行方案的达标向量，先比较最高优先级相位，再依次向后。输出同时指明各未达标相位所欠的精度。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。window 和 seed 引用监督窗 ID。region 是高分辨率图的半开矩形 [x0,y0,x1,y1]，grad 按行给对应梯度。export 请求设备权重。

## 设备联调资料

较大的联合设备资料位于 `inputs/qualification.json`，其中 `sourceShape` 是低分辨率 HWC，`generator` 提供基础源块，窗口坐标均以放大图左上为原点且半开。分组的中心值是可供普通核读取的源特征，校准片中逐槽 `signedSamples` 是固定输入上沿同一 3×3 足迹取得的参与值，可正可负。样本表按 `[device, phase]` 顺序列出，某行一个 `weightId` 未在目标机型该相位槽位图中时不参与。设备对每片施加绝对输出误差线，值由解码权重完成的相关相对于当前完整权重的结果比较。普通权重舍入遵循上文，`exactSlots` 为整个共享包的高精个数。`deviceMask` 用 `phase` 顺序列出该机型每相位支持的权重 ID，资格按 `priority` 的 `[device, phase]` 顺序作字典序比较，资格相同的方案先取高精槽更少者，再按排序后的 ID 序列比较。`export` 同批两机型使用同一物理包。设备通过包索引获得其相位实际需要的值，单个权重只能有一种物理值。`footprints` 中各值为 [通道, 相对行, 相对列]，相位按 [0,0]、[0,1]、[1,0]、[1,1] 编号。`revision2` 用对应机型的掩码替换 `deviceMask`，校准中的旧槽仍保留作板端比较，实际不支持的槽不参与。`loss` 最后一项是每个有效输出像素的上游标量梯度。`supersede` 含机型及新槽位图修订，其前引用该机型旧修订的监督票据不能被应用。
`qualification.mjs` 仅根据源块位置产生输入张量。`maxWorkBytes` 包含训练过程中临时展开、尚未交付的高分辨率输出和逆向散加中间缓冲，不包括引用的只读输入和交给调用方的最终张量。
